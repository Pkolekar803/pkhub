def get_completion(prompt, model="gpt-3.5-turbo"):
    messages = [{"role": "user", "content": prompt}]
    response = openai.ChatCompletion.create(

Iterative Prompt Development
As is the case in any kind of programming language the first solution that you might think of might not be the best or the most effective solution and it almost always involves an iterative process of working through the solution to find the most effective one.

The same applies for the Prompt Engineering.
It is rare for the first prompt to work perfectly, but having a good process for refining the prompt is key.
The process is similar to the iterative process of developing machine learning models.

Summarizing
Summarizing is the process to summarize text, which can be useful for quickly glancing over a large volume of text.

We can use Large Language Model to summarize for a given a large amount of text.

An use case in which this type of process can be used:

Let's say you have a large amount of reviews from thousands of users and it would be very tiring to have a look at every individual review and understand what they are trying to convey.

It would be better to use a large language model to summarize each review to a specific number of words so that it'd be easier to go over them.
You can also ask it to extract information from the text rather than summarize it, depending on how you wish to summarize it.


Code - Example
Let's try to summarize a product review
---------------------------------------
prod_review = """
I recently purchased a 10-pack of Amazon Basics AA High-Performance Alkaline Batteries, and I'm very happy with them. They arrived quickly with free shipping for Prime members, and they've been working great in all of my devices. I've been using them in my remote controls, flashlights, and toys, and they've all been lasting a long time. I'm impressed with the quality of these batteries, and I would definitely recommend them to others. They're a great value for the price, and they're reliable and long-lasting. I'm glad I made the switch to Amazon Basics batteries.
"""
In the above code we define a variable which contains the review of a product
------------------------------------------------------------------------------


Code - Example Contd
--------------------
prompt = f"""
Your task is to generate a short summary of a product review from an ecommerce site. 

Summarize the review below, delimited by triple 
backticks, in exactly 10 words. 

Review: ```{prod_review}```
"""
response = get_completion(prompt)
print(response)

Inferring
Large language models can also be used for inferring tasks such as

Sentiment analysis
Emotion recognition
Information extraction
Topic inference
The use cases of Inferring can be

Extract different types of information from a piece of text such as
Identifying the sentiment of a product review
Extracting the item and brand from a review
Determining the topics covered in a news article.


Traditional Development
In the conventional machine learning workflow, you would need to gather the label data set, train the model, figure out how to deploy the model somewhere in the cloud, and then extract a sentiment, positive or negative, from a piece of text.

And while that has some potential for success, going through the process is time-consuming.

And for each of the tasks like

Sentiment analysis
Emotion recognition
Information extraction
the machine learning model must be trained individually which takes considerable effort for the developer.

For many of these tasks, you can simply create a prompt and have it start producing results straight away, which is one of the really good things about a large language model.

And that allows for incredibly quick application development.



Code - Example
--------------
Let's try to identify the emotions from the previous review
-----------------------------------------------------------
prompt = f"""
Identify a list of emotions that the writer of the following review is expressing. Include no more than five items in the list. Format your answer as a list of lower-case words separated by commas.

Review text: '''{prod_review}'''
"""
response = get_completion(prompt)
print(response)

Output:
--------
happy, impressed, recommend, glad, satisfied




Transforming
Large language models can also be used in Transforming tasks, such as

Translation
Translating text from one language to one or many languages.
The translated text can be either formal or informal way of speaking.
Spelling and grammar correction
Ask the model to proofread a text which you're not sure is grammatically correct and output the corrected text
Format transformation
Providing HTML and getting the equivalent JSON format.

Expanding
Expanding is the task of taking a short piece of text and having the large language model generate a longer piece of text.

An use case in which this type of process can be used:

Generating personalized emails based on customer reviews.
Note:

Chatbot
A chatbot is a piece of software that attempts to mimic human conversation through text or voice interactions.

Large language model can be used to build a custom chatbot, such as an AI customer service agent or an AI order taker for a restaurant.

An Example of what a chatbot looks like

User: tell me a joke

Assistant: Why did the chicken cross the road

User: I don't know

Assistant: To get to the other side
